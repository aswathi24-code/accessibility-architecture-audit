# Accessibility Audit Report

## Findings

1. **Form labels** — High priority
2. **Keyboard focus** — High priority
3. **Color contrast** — High priority
4. **Heading structure** — Medium priority
5. **Responsive design** — Medium priority

## Recommendations

- Add clear labels to all forms.
- Provide visible keyboard focus.
- Improve color contrast.
- Use logical heading levels.
- Test layouts on mobile and desktop.

## Testing

The audit uses Lighthouse and manual keyboard navigation.
